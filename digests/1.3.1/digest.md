# Дайджест релиза analyzer-agent-service 1.3.1 (2026-08-20)

> Источник: `C:\dev\analyzer-agent-service`, диапазон `v1.3.0..v1.3.1`.
> Разведывательный обзор родительского проекта. LUNA — независимый проект:
> ничего отсюда не переносится автоматически, это материал для решения.

## TL;DR
- Брошенные сессии удаляются вместе с диском по idle TTL (дефолт 8 часов); живой ход и висящий HITL не трогают.
- UI без админ-входа показывает только сессии этого браузера (`localStorage`); админ видит весь под.
- Метки `created_at` / `last_activity` захардкожены в GMT+3 — для LUNA это минус, не плюс.

## Нововведения (по продукту)
### Автоудаление простых сессий
- **Что:** `SESSION_IDLE_TTL_SECONDS` (дефолт 28800), обход каждые `SESSION_SWEEP_INTERVAL_SECONDS`. `0` выключает sweeper.
- **Зачем:** долгоживущий под не копит мёртвые workspace на диске. Закрывает TD-13 родителя.

### Видимость сессий в UI
- **Что:** рейл по умолчанию — только id из `localStorage`; кнопка «вход» раскрывает все сессии пода. В шапке чата полный `session_id`.
- **Зачем:** на общем стенде не светить чужие сессии; админ всё же может зайти в любую.

## Техническая реализация
### Sweeper
- **Как сделано:** `SessionManager.sweep_idle` в lifespan крутится `asyncio.create_task`. Skip `is_busy` и непустой HITL pending. Удаление — `delete_session` + teardown sandbox.
- **Ключевые файлы:** `core/agent/session.py` (+45/-4), `core/app/server.py` (+32), `core/config.py` (+2).
- **Заметки:** в LUNA на старте уже есть `_wipe_stale_sessions` (всё стереть после рестарта процесса). Sweeper — про *живой* процесс, который крутится днями. Для `luna-web` это полезно независимо от sandbox.

### Часовой пояс
- **Как сделано:** `_SESSION_TZ = timezone(timedelta(hours=3))` для `now`, `created_at`, `last_activity` и cutoff sweeper.
- **Ключевые файлы:** `core/agent/session.py`.
- **Заметки:** стенд родителя в Москве. Хардкод ломает смысл ISO-8601. В LUNA оставлять UTC (или явный offset из env), не копировать +03:00.

## Кандидаты на перенос в LUNA
| Идея | Ценность для LUNA | Сложность | Совместимо с LUNA | Заметка |
|------|-------------------|-----------|-----------------|---------|
| Idle TTL + periodic sweep | высокая | низкая | да | Прямо на текущий `SessionManager`. TTL=0 как выключатель. Не привязывать к sandbox teardown. |
| `session_id` в шапке чата | низкая | низкая | да | Удобно при нескольких вкладках. |
| Рейл «только мои сессии» | низкая | низкая | частично | В LUNA один пользователь на процесс; админ-логин родителя ни к чему. Фильтр по `localStorage` можно как UX, не как безопасность. |

## Что НЕ тянем
- **Фиксированный GMT+3** — не переносим; метки сессии должны быть UTC (или локаль пользователя).
- **Админ-вход, чтобы увидеть все сессии пода** — мультиарендность стенда, не модель LUNA.
- **Teardown Linux-sandbox в `delete_session`** — не из чего снимать.
