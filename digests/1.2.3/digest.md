## Нововведения (по продукту)
### Навигатор guidebook
- **Что:** `INDEX.md` ведёт по задачам; в промпте правило «прочитай гайд (и grep), не импровизируй».
- **Зачем:** агент меньше выдумывает процедуры, которых нет в файлах.

### 3D, отчёты, НСИ
- **Что:** `guidebook/3d-analysis/` (guide, best practices, OCP-cheatsheet, three.js-сцена), `reporting.md`, `reference.md`, `sketches.md`. Vision явно ограничен 2D.
- **Зачем:** 3D через код по гайду; отчёт — один self-contained файл с inline-картинками.

### Копирование узлов ТП
- **Что:** `tp_copy_node` из аналогового техпроцесса, в т.ч. пакетно с list-source вроде `/selectedRow`.
- **Зачем:** собрать новый ТП из кусков похожего, не потеряв уникальность ID.

## Техническая реализация
### Guidebook-навигатор
- **Как сделано:** переписан `INDEX.md` и правила в `main_agent.ru.md`: до любой задачи — read/grep по guidebook.
- **Ключевые файлы:** `core/procedures/guidebook/INDEX.md` (+52/-16), `core/procedures/main_agent.ru.md` (+19/-21).
- **Заметки:** это политика промпта, не новый рантайм. Легко пробовать в LUNA точечно.

### 3D-гайды
- **Как сделано:** markdown + статика three.js рядом с гайдом; в образе OCP/networkx вместо VTK.
- **Ключевые файлы:** `core/procedures/guidebook/3d-analysis/**`, `core/procedures/guidebook/reporting.md` (+213).

### tp_copy_node
- **Как сделано:** копирование поддерева + `_regenerate_ids` / sequence; защита от `workpiece is None` и не-dict элементов.
- **Ключевые файлы:** `core/agent/tools/techprocess_edit_tools.py` (+322/-6).
