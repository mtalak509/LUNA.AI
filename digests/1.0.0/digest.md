# Дайджест релиза analyzer-agent-service 1.0.0 (2026-07-09)

> Источник: `C:\dev\analyzer-agent-service`, диапазон `v0.8.0..v1.0.0`.
> Разведывательный обзор родительского проекта. LUNA — независимый проект:
> ничего отсюда не переносится автоматически, это материал для решения.

## TL;DR
- Первый рабочий веб-UI: сессии, чат со стримом и reasoning, HITL-карточки, file viewer, чекпоинты.
- На старте процесса зачищаются директории сессий прошлого запуска (реестр in-memory).
- Документная вкладка заточена под `techprocess.json` — это как раз то, что LUNA позже выкинул.
- Починен обрыв vLLM «model not alive», чтобы ход не висел вечно.

## Нововведения (по продукту)
### Консоль агента
- **Что:** `devfront/static/` — управление сессиями, лента ответа, HITL, просмотр файлов, откат чекпоинтов.
- **Зачем:** тем же HTTP/SSE API можно пользоваться из браузера, не только из REPL.

### Вкладка документа
- **Что:** загрузка и просмотр канонического `techprocess.json`.
- **Зачем:** оператор видит «главный» документ сессии.

### Жизненный цикл сессий
- **Что:** `_wipe_stale_sessions` на старте; dev-эндпоинты `fs/tree`, `fs/file`, `checkpoints` за флагом.
- **Зачем:** после рестарта процесса диск не копит мёртвые зоны; UI может ходить по файлам.

## Техническая реализация
### Devfront
- **Как сделано:** один `app.js` (~2k строк) + `style.css` + разметка. Скролл чата через `scrollToBottom`, чтобы HITL-карточка оставалась в кадре.
- **Ключевые файлы:** `devfront/static/app.js` (+2006), `devfront/static/style.css` (+1030), `devfront/static/index.html` (+145/-13).

### Сервер
- **Как сделано:** wipe stale в lifespan; нормализация вложенных `subagent_event`; обработка ошибки vLLM в `base.py`.
- **Ключевые файлы:** `core/agent/server.py` (+211/-3), `core/agent/base.py` (+38/-1).
- **Заметки:** in-memory `SessionManager` по-прежнему не переживает рестарт — wipe это признаёт, а не чинит.
