# Дайджест релиза analyzer-agent-service 1.1.0 (2026-07-15)

> Источник: `C:\dev\analyzer-agent-service`, диапазон `v1.0.1..v1.1.0`.
> Разведывательный обзор родительского проекта. LUNA — независимый проект:

## TL;DR
- HTTP-слой разрезан на `core/app/` (сессии, ход, workspace, fs/checkpoints, SSE) — эту раскладку LUNA взял.
- Появились профили сессии `cait` / `standalone` и поле `pointer` (JSON Pointer выбранного раздела ТП).
- `GET`/`PUT .../workspace/techprocess` — отдельный ресурс канонического документа.
- LUNA позже явно выкинул `pointer` (0.1.1) и не завёл профили `cait`/`standalone`.

## Нововведения (по продукту)
### Профили сессии
- **Что:** `POST /sessions` требует `cait` или `standalone`; профиль хранится в сессии.
- **Зачем:** один сервер, два режима работы (с ЦАИТ и автономно).

### Указатель раздела
- **Что:** `POST /turn` принимает `pointer`; агент видит выбранный раздел `techprocess.json`.
- **Зачем:** UI «кликнул узел — агент думает про этот узел».

### Документ рабочей области
- **Что:** получить/заменить техпроцесс незанятой сессии.
- **Зачем:** загрузить ТП, не создавая сессию заново.

## Техническая реализация
### Раскладка HTTP
- **Как сделано:** `core/app/server.py` + роутеры `sessions` / `turn` / `workspace` / `dev`; SSE вынесен в `core/app/sse.py`. Старый `core/agent/server.py` удалён. `core/orchestrator/app.py` — переезд бывшего `core/app.py`.
- **Ключевые файлы:** `core/app/server.py` (+98), `core/app/sse.py` (+159), `core/app/routes/*.py`, `core/agent/server.py` (удалён, −582).
- **Заметки:** это полезный шов. LUNA живёт в этой раскладке.

### Pointer
- **Как сделано:** поле на `TurnRequest` → runtime context → `ContextInjectMiddleware`.
- **Ключевые файлы:** `core/agent/session.py` (+19/-13), `core/agent/middleware/context_inject.py` (+31).
- **Заметки:** в LUNA значение доходило до контекста, но никто его не читал — поэтому поле сняли.

## Что НЕ тянем
- **Профили `cait` / `standalone`** — доменная развилка «есть ЦАИТ / нет ЦАИТ».
- **`pointer` на ходе** — привязка к дереву техпроцесса. LUNA 0.1.1 удалил поле сознательно.
- **`/workspace/techprocess` как особый ресурс** — нет канонического документа.
- **`core/orchestrator/`** — слой, которого в LUNA нет.
